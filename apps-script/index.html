操作流程

  1. 設定 API Key — 輸入您的 OpenAI 或 Google AI API Key
  2. 定義專案 — 填寫產品資訊與廣告目標
  3. 生成文案 — AI 自動產生多組廣告文案
  4. 生成圖片 Prompt — AI 產出可用於 Midjourney/DALL-E 的 Prompt
  5. 組合測試 — 搭配文案與圖片 Prompt，準備 A/B 測試
  6. 匯出結果 — 下載 CSV 或寫入 Google Sheets
🔑

API Key 安全提示

  • API Key 透過 Google Apps Script 後端處理，不在前端暴露
  • 建議為此應用設定獨立的 API Key 並設定使用上限
  • 切勿將 API Key 分享給他人

使用說明與幫助

1. 設定 API Key

支援 OpenAI (GPT) 和 Google AI (Gemini)。如何取得：

  • OpenAI：前往 platform.openai.com → API Keys → 建立新的 Key
  • Google AI：前往 aistudio.google.com → 取得 API Key

2. 專案設定

填寫產品資訊、選擇廣告目標、描述目標受眾。越詳細越好。

3. 文案生成

選擇風格後點擊生成，AI 將產出多組含標題、內文、CTA 的文案。

4. 圖片 Prompt 生成

AI 會產出可直接用於 Midjourney / DALL-E / Stable Diffusion 的英文 Prompt，附帶中文說明、建議平台與比例。

5. 素材組合

選擇文案與圖片 Prompt 進行搭配，建立多個 A/B 測試組合。

6. 匯出結果

CSV 下載、複製到剪貼簿，或直接寫入 Google Sheets。

文案 Prompt - 產品描述怎麼寫？

好的描述：

這是一款針對 25-35 歲上班族的智能水壺，主打自動提醒喝水功能，搭配 App 追蹤每日飲水量。售價 NT$1,200，比同類產品便宜 30%。

不好的描述：

水壺，很好用

技巧要點

  • 具體化：包含價格、功能特點、目標用戶
  • 差異化：說明與競品的不同
  • 場景化：描述使用場景
  • 數據化：提供具體數字

Q: API Key 安全嗎？

A: API Key 透過 Google Apps Script 後端處理，不會暴露在瀏覽器中。但仍建議設定使用上限。

Q: 使用 AI API 需要費用嗎？

A: 是的，呼叫 AI API 會產生費用。GPT-4o-mini 費用非常低廉，生成一次約 0.01-0.05 美元。

Q: 什麼是 A/B 測試？

A: 同時投放不同版本的廣告素材，比較成效（點擊率、轉化率），找出最佳組合。

Q: 圖片 Prompt 怎麼用？

A: 將生成的英文 Prompt 複製到 Midjourney、DALL-E 或 Stable Diffusion 等工具中，即可生成對應圖片。

Q: CTA 是什麼？

A: CTA (Call to Action) 是「行動呼籲」，例如「立即購買」、「免費試用」、「了解更多」。
