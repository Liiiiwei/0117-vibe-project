使用說明與幫助

操作指引

1. 設定 API Key

在「API 設定」區塊中輸入您的 AI 服務 API Key。支援 OpenAI 和 Google AI (Gemini)。

如何取得 API Key：

  • OpenAI：前往 platform.openai.com → API Keys → 建立新的 Key
  • Google AI：前往 aistudio.google.com → 取得 API Key

2. 專案設定

填寫您的產品/服務資訊，選擇廣告目標，描述目標受眾。越詳細的描述，AI 生成的結果越精準。

3. 文案生成

選擇文案風格後點擊「生成文案」，AI 將產出多組文案供您選擇。

4. 圖片生成

描述期望的圖片風格與元素，AI 將為您生成廣告圖片。

5. 素材組合

選擇喜歡的文案與圖片進行搭配，建立多個 A/B 測試組合。

6. 匯出結果

將組合結果匯出為 CSV 檔案、複製到剪貼簿，或寫入 Google Sheets。

技巧要點

  • 具體化：包含價格、功能特點、目標用戶等具體資訊
  • 差異化：說明產品與競品的不同之處
  • 場景化：描述使用場景，讓 AI 更好地理解產品定位
  • 數據化：提供具體數字（折扣、效果數據等）

常見問題 (FAQ)

Q: API Key 會被儲存嗎？

A: API Key 僅暫存於您的瀏覽器 Session Storage 中，關閉瀏覽器標籤頁後即自動清除。不會傳送到任何第三方伺服器。

Q: 使用 AI API 需要費用嗎？

A: 是的，呼叫 AI API 會產生費用，由各 AI 服務商向您收取。建議在 API 服務商後台設定使用上限。

Q: 什麼是 A/B 測試？

A: A/B 測試是指同時投放不同版本的廣告素材，比較它們的成效（如點擊率、轉化率），找出表現最佳的組合。

Q: 為什麼圖片生成很慢？

A: 圖片生成需要較多的運算資源，通常需要 10-30 秒。請耐心等待。

Q: 生成的素材可以商用嗎？

A: 透過 OpenAI DALL-E 或 Google Imagen 生成的圖片，請參考各服務商的使用條款。一般而言，付費 API 生成的內容可用於商業用途。

Q: CTA 是什麼？

A: CTA (Call to Action) 是「行動呼籲」，指廣告中引導受眾採取行動的文字，例如「立即購買」、「免費試用」、「了解更多」。
